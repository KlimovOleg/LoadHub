# Реестр «учебное → коммерческое»

Технический долг учебных итераций. Пункт закрывается, когда код переделан **и** есть тест/проверка.
Этап не считается пройденным, пока его пункты открыты.

| # | Учебный вариант (A) | Коммерческий вариант (B) | Этап | Статус |
|---|---|---|---|---|
| 1 | `$request->validate()` в контроллере | Form Request классы | 1 | ☐ |
| 2 | Возврат моделей из контроллера | API Resources, единый формат ответа и ошибок | 1 | ☐ |
| 3 | Логика в контроллере | Action-классы + DTO, тонкие контроллеры | 3 | ☐ |
| 4 | Статусы строками | PHP enum + машина переходов состояний | 3 | ☐ |
| 5 | Роль — колонка `role` в `users` | spatie/laravel-permission + Policies | 3 | ☐ |
| 6 | Стандартная структура `app/Models`, `app/Http` | Модули `app/Modules/*` + архитектурные тесты | 3 | ☐ |
| 7 | Очередь `database` | Redis + Horizon, очереди по приоритетам | 4 | ☐ |
| 8 | Синхронная отправка уведомлений | Через очередь, ретраи, идемпотентность | 4 | ☐ |
| 9 | Файлы на локальном диске | S3 (MinIO), временные подписанные ссылки | 4 | ☐ |
| 10 | `axios` прямо в компонентах | API-клиент + composables + Pinia | 6 | ☐ |
| 11 | Типы ответов API вручную | Генерация из OpenAPI (Scramble) | 6 | ☐ |
| 12 | Самописная валидация форм | VeeValidate + Zod, ошибки 422 в полях | 6 | ☐ |
| 13 | Scout, драйвер `database` (FULLTEXT) | Scout + Meilisearch, индексация через очередь | 7 | ☐ |
| 14 | Кеш без инвалидации | Инвалидация, теги, `Cache::flexible`, locks | 7 | ☐ |

| 16 | Laravel Events внутри процесса | Transactional Outbox + RabbitMQ | 8 | ☐ |
| 17 | Dev-образ Docker | Multi-stage prod-образ, не от root, CD | 9 | ☐ |
